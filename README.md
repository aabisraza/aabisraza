## 🔬 Currently Building: AirBridge

### An Environmental Data Analysis Project

**Status: Actively in development**

AirBridge is my current independent technical project, exploring the use of real-world environmental data to investigate air-quality patterns across selected monitoring locations in Lahore, Pakistan, and Seoul, South Korea.

The project uses the OpenAQ API to collect historical PM2.5 measurements and Python-based workflows to process, validate, and analyse environmental observations.

Rather than simply collecting data, an important part of AirBridge is investigating its reliability and limitations.

**Current development focus:**

- Collecting historical PM2.5 measurements through the OpenAQ API.
- Investigating missing observations and monitoring interruptions.
- Evaluating hourly and daily data completeness.
- Examining unusual measurements and potential data-quality issues.
- Developing reproducible data-processing and analytical workflows.
- Exploring environmental patterns through statistical analysis.

**Current technology stack:**

`Python` `Pandas` `Requests` `OpenAQ API` `Git` `GitHub`

**Current milestone:**

Successfully implemented historical data collection for two selected monitoring locations, producing an initial dataset of 18,436 PM2.5 records. Data-quality investigation and validation are ongoing.

**Future development plans:**

- Structured historical data storage.
- Interactive environmental data visualisation.
- Statistical and exploratory analysis.
- Potential forecasting experiments, subject to data suitability and rigorous evaluation.

The project is being developed progressively, with an emphasis on authentic data, transparent methodology, and reproducibility.
